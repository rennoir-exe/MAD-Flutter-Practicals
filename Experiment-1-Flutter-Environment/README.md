# Experiment 1 – Install and Configure Flutter Development Environment

## Aim

To install and configure the Flutter development environment and prepare the system for Flutter application development.

## Objective

To install the Flutter SDK, configure Android Studio and Android Emulator, and verify the Flutter environment using Flutter tools.

## Course Outcome

Apply Flutter framework and Dart programming to develop cross-platform mobile applications, demonstrating proficiency in engineering fundamentals and tools.

## Theory

Flutter is an open-source UI framework developed by Google for building cross-platform applications using the Dart programming language.

The Flutter development environment consists of the Flutter SDK and supporting tools required to develop, run, and test applications.

The `flutter doctor` command is used to check whether the required Flutter dependencies and development tools are correctly installed and configured.

## Software Requirements

* Flutter SDK
* Android Studio
* Android SDK
* Android Emulator
* Dart SDK
* Windows Operating System

## Procedure

### Step 1: Install Flutter SDK

Download and install the Flutter SDK and configure the Flutter path.

### Step 2: Install Android Studio

Install Android Studio along with the required Android SDK and development tools.

### Step 3: Configure Android Emulator

Create and configure an Android Virtual Device using Android Studio.

### Step 4: Verify Flutter Installation

Open the terminal and execute:

```bash
flutter doctor
```

Check the Flutter environment and installed dependencies.

### Step 5: Accept Android Licenses

Execute:

```bash
flutter doctor --android-licenses
```

Accept the required Android SDK licenses.

### Step 6: Final Verification

Run:

```bash
flutter doctor
```

Verify that the required components are properly configured.

## Output

The Flutter development environment was successfully installed and verified using the Flutter Doctor tool.

## Conclusion

The Flutter development environment was successfully installed and configured. The Flutter SDK, Android development tools, and required dependencies were verified using the `flutter doctor` command. The practical helped in understanding the installation and configuration of the Flutter development environment.
